# SOP-OBR-01 — Recepció de mercaderia

**Estat:** borrador · **Mòdul:** Kronos Recepcions / Portal Obrador  
**Objectiu:** Registrar l’entrada de matèria primera amb traçabilitat (proveïdor, lot, temp., estat).

## Passos (resum)

1. Obrir **Recepcions** → Nova recepció (o Foto/PDF albarà OCR al portal/Kronos).
2. Revisar proveïdor (CIF/nom), lot proveïdor, temperatura, estat (bo/regular/rebutjat).
3. Completar observacions si rebutjat; desar.
4. Verificar al llistat (filtres / incomplets APPCC al dashboard).

## Registres

Taula `obrador_recepcions` (+ matching proveïdor Holded si aplica).
