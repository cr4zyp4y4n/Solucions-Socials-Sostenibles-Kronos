# SOP-OBR-02 — Associació producte–proveïdor

**Estat:** borrador · **Mòdul:** Kronos Productes  
**Objectiu:** Vincular ingredients/proveïdors esperats a cada producte elaborat.

## Passos (resum)

1. Pestanya **Productes** → seleccionar producte.
2. Afegir proveïdors / ingredient_nom segons escandall previst.
3. Desar; verificar que al crear lot només surten recepcions aptes d’aquests proveïdors.

## Registres

`obrador_producte_proveidors`.
