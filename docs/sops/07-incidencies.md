# SOP-OBR-07 — Gestió d’incidències

**Estat:** borrador · **Mòdul:** Kronos Incidències  
**Objectiu:** Obrir, posar en revisió i tancar incidències de lot o sensor amb checklist.

## Passos (resum)

1. Alta manual (lot) o automàtica (IoT fora de rang / sense senyal).
2. **En revisió** → tancament amb checklist APPCC i notes.
3. Enllaç des del dashboard operatiu.
