# SOP-OBR-06 — Confirmació d’entrega

**Estat:** borrador · **Mòdul:** Kronos / Portal  
**Objectiu:** Marcar expedició entregada al destí (amb o sense OK client).

## Passos (resum)

1. Llistat expedicions en trànsit → **Marcar entregat** (o portal `?entregar=1`).
2. Triar si el client ha acceptat el producte.
3. Verificar estat `entregat`.
