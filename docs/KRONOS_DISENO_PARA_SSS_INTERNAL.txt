OBJETIVO DE ESTE REDISEÑO:
Que Internal se sienta como Kronos: mismos colores, tipografía soberana del sistema,
cards claras, verde #4CAF50 como acento, sin estética “landing genérica AI”
(evitar purple gradients, cream+serif terracotta, broadsheet, glow excesivo).

================================================================================
3. TIPOGRAFÍA
================================================================================

font-family (Kronos body / index.css):
  -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif

NO introducir: Inter como default de marketing, display serifs, mono solo para códigos.

Jerarquía típica Kronos:
  - Título página / hero corto:  font-weight 700–800, ~22–28px, color text
  - Subtítulo:                   13–14px, textSecondary, line-height 1.45
  - Labels de campo:             12px, font-weight 700, textSecondary
  - Botón primario:              14px, font-weight 800, color #fff
  - Botón secundario:            14px, font-weight 700
  - Badge / chip:                10–11px, font-weight 800, uppercase a veces

Splash / branding usa Arial explícito en algunos textos; para web Internal
basta el stack del sistema.

================================================================================
4. FORMA, RADIO Y ESPACIADO
================================================================================

Radios frecuentes:
  - Cards / modales login:     16px
  - Botones:                   8–10px (Firma usa 10; login a veces 8)
  - Inputs:                    8–10px
  - Chips / badges:            12px o pill 999
  - Logo en header:            8px
  - Iconos circular status:    50%

Padding:
  - Card estándar:             16–20px
  - Página:                    24px
  - Login card:                24–32px
  - Botón md:                  10px 14px
  - Botón sm:                  7px 11px

Gaps: 8 / 12 / 16 / 18

Bordes: siempre 1px solid colors.border (casi nunca bordes gruesos).
Sombras: muy suaves; Kronos no es “multi-layer neumorphism”.

================================================================================
5. COMPONENTES (patrones Kronos)
================================================================================

CARD:
  background: surface (#fff)
  border: 1px solid #e0e0e0
  border-radius: 16px
  padding: 20px
  (opcional) box-shadow: 0 2px 8px rgba(0,0,0,0.04)

BOTÓN PRIMARIO:
  background: #4CAF50
  color: #fff
  border: none
  border-radius: 10px
  font-weight: 800
  padding: 10px 14px
  hover: ligeramente más oscuro (#43A047) o opacity 0.9
  disabled: opacity 0.55

BOTÓN SECUNDARIO / GHOST:
  secondary: border 1px #e0e0e0, background #fafafa o #fff, color #333, weight 700
  ghost: transparente, color textSecondary, weight 600

INPUT:
  padding: 10px 12px
  border-radius: 10px
  border: 1px solid #e0e0e0
  background: #fafafa (o surface)
  focus: borderColor = #4CAF50

NAV / HEADER:
  fondo blanco, borde inferior 1px #e0e0e0
  logo SSS + nombre producto en weight 700
  ítems: textSecondary; activo = primary + weight 600–700
  botones nav tipo chip con borderRadius 8

BADGE ESTADO:
  fondo color+15% alfa, texto del color, border color+30% alfa, radius 12, weight 600

MOTION (framer-motion en Kronos):
  - Entrada cards: opacity 0→1, y 8→0, ~0.25–0.28s
  - Splash: scale logo + barra progreso verde
  - Evitar animaciones ruidosas / parallax marketing

ICONOS:
  Kronos usa feather-icons-react / lucide en portales.
  Trazo fino, color primary o textSecondary. No emojis como iconografía principal
  (Internal hoy usa 🖥️📱; sustituir por iconos SVG si se rediseña).

7. LAYOUT SUGERIDO PARA INTERNAL (rediseño)
================================================================================

Estructura tipo Kronos (limpia, no landing ruidosa):

1) HEADER fijo o sticky
   - Logo SSS + "SSS INTERNAL"
   - Nav: Inicio | Descargas | Fichaje | Contacto | Iniciar sesión
   - Fondo surface, borde inferior sutil

2) HERO corto (primera viewport)
   - Un solo título: SOLUCIONS SOCIALS / SSS INTERNAL
   - Una frase: Portal de descargas y herramientas internas
   - Sin stats, sin collage, sin badges flotantes sobre imagen
   - Fondo #fafafa; opcional franja/acento verde muy suave

3) GRID DE APPS (Desktop / Mobile)
   - 1–2 cards (radius 16) con icono, título, descripción corta
   - CTA primario "Descargar" (verde) + secundario "Documentación" / "Notas"
   - Misma jerarquía tipográfica Kronos

4) SECCIÓN FICHAJE / LOGIN
   - Card centrada estilo LoginPage Kronos (radius 16, padding 32)
   - Inputs focus verde

5) FOOTER
   - Privacidad | Cookies | Ayuda
   - Copyright
   - Tipografía pequeña textSecondary

Responsive:
  - Mobile-first: nav colapsable (ya hay menú)
  - Cards a 1 columna en móvil, 2 en desktop
  - Evitar overflow horizontal

================================================================================
8. QUÉ NO HACER (anti-patrones)
================================================================================

- Gradientes púrpura / indigo “AI default”
- Fondo cream + serif + terracotta
- Layout periódico/broadsheet
- Dark mode forzado sin toggle
- Pills rounded-full en exceso + multi-shadow glow
- Emojis como sustituto de iconos de producto
- Hero con stats, chips flotantes, collage de imágenes
- Cards dentro del hero sin necesidad
